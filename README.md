# 2D-Advection-Based-Landscape-model

Note that this is a old project which was aimed to investigate the relief-inversion hypothesis for the formation of the Matheran plateau, Western Ghats.
The codes models erosion primarily through advective transport and numerically simulated landscape evolution under varying initial and boundary conditions; demonstrated that the simplified model can generate plateau-like topographic structures, supporting the possibility of relief inversion as a mechanism for plateau formation.
 
basic code fluvial.ipynb contains the base code escarpment and back wasting in generalized setting.
simple analysis.ipynb contains the code for analysis of survival times of plateaus in various different settings.

The motivation for this model comes mainly from Alan D. Howard.
This is an old project which was done as part of regular coursework in the course Landscapes and their evolution taken by Prof. Argha Banerjee.
